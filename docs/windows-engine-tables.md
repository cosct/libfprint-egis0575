## 3. 关键代码位点（重同步反汇编定位）

- **0x15515**：`lea rsi,[rip+…]` = 0x40130 → 卷积循环 `imul` 图像梯度×权重核
  = **描述子构建函数**
- **0x153bf/0x153e4**：`movzx word [0x40320 + idx*2]` + `720−x`
  = **梯度方向计算**

## 4. 复刻迭代记录（关键领悟：轴向 ≠ 取向）

**滤波器组重解读**：11 个核不是 11 个尺度，而是 **11 个取向的脊线匹配
滤波器**（对角取向等效支撑更长 → 抽头更多）。正确实现：对每取向 θ 做
定向 FIR → 响应取最大 = 增强图 + 取向图（可导向滤波器组）。轴向可分离
平滑实验已证伪（兴趣点塌缩、真假倒挂）。

| 变体 | 真手指票 | 冒充票 | 结论 |
|---|---|---|---|
| 32bit + Lowe + 中值 | 0 | — | 描述子太弱 |
| 128bit + Lowe + 中值 | 0-1 | — | Lowe 杀真对（邻点太像）|
| 128bit 无Lowe + 平移桶聚类 | 5,3,3 | 0,3,5 | 首现信号 |
| 256bit(16bin) | 3,2,2 | 3,2,3 | 细分不稳（SNR 限制）|
| + 轴向FIR平滑 | 0 | 3-4 | 证伪（轴向≠取向）|
| **+ 11取向滤波器组** | **9,7,8 / 5 / 7,7,6** | 3-7 | 票数仍重叠 |
| + 加权分数 Σ(128−h) | 均值156 (min107) | 均值86 (max137) | **1.8x 偏移，仍重叠** |

方法论沉淀：capstone 失步重同步、弱描述子场景不用 Lowe、票数不判别
要用加权分数。兴趣点几何重复性 52% = 管线健康底座。

## 5. 获胜方案（全部可溯源，🏆 2026-09-13 凌晨）

1. 11 取向脊线匹配滤波（抽头提取自 DLL）→ 增强图+取向图
2. 滤波响应极大值兴趣点 + 密度 NMS（52% 跨按压重复性）
3. 512bit 顶档描述子：4×4 区域 × 32 方向 bin，DLL 金字塔权重，
   主方向 = 获胜滤波取向
4. 海明 NN（预算 115/512，无 Lowe）→ 平移簇聚类（8px 桶众数，非迭代
   RANSAC）→ 角度众数投票
5. Windows 评分 Σ(128−h) − 未匹配特征惩罚(h/2)
6. 双帧模板库一致性（对抗位置特异偶然对齐）
